# Д1. Сжатие изображений с помощью SVD

Первое задание курса «Машинное обучение и компьютерная алгебра» (осень 2026).
Разложение изображения по сингулярным числам (SVD) и сжатие с контролируемой потерей качества.

**Решение:** [`D1_SVD_solution.ipynb`](./D1_SVD_solution.ipynb) — запускается от начала до конца без ошибок, все блоки автопроверки проходят.

![Результаты сжатия при разных рангах](./results_grid.png)

## Что сделано

Выполнена продвинутая (бонусная) часть задания: SVD применяется **отдельно к каждому из трёх RGB-каналов**, без перевода в оттенки серого. Сборка каналов — через broadcasting, без циклов по пикселям.

Каждый цветовой канал — это матрица `A` размера `height × width`. Через `np.linalg.svd(A, full_matrices=False)` она раскладывается на `A = U · Σ · Vᵀ`. Оставляя только первые `r` сингулярных чисел, получаем приближение ранга `r` — по теореме Эккарта–Янга это наилучшее приближение матрицы среди всех матриц такого ранга (в норме Фробениуса). Восстановление считается без построения диагональной матрицы:

```python
reconstructed = (U[:, :r] * s[:r]) @ Vt[:r, :]
```

Тестовое изображение — цветное фото `astronaut` 512×512 из `scikit-image` (не требует интернета). Чтобы подставить свою картинку, достаточно раскомментировать одну строку в функции загрузки.

## Ответы на вопросы задания

**При каком ранге качество перестаёт отличаться от оригинала?** Примерно с `r ≈ 100` (PSNR ≈ 33 дБ) разница на глаз уже не видна; «почти неотличимо» — уже с `r ≈ 50–70`. То есть около 100 компонент из 512 несут почти всю визуальную информацию.

**Для какого ранга достигается сжатие в 10 раз?** Из `сжатие = h·w / (4·r·(h+1+w)) = 10` получаем `r = h·w / (40·(h+1+w)) ≈ 6`. На целых рангах: `r=5 → 12.8x`, `r=6 → 10.7x`, `r=7 → 9.1x`. Значит сжатие в 10 раз — это примерно ранг 6, но качество при нём ещё грубое.

**Почему ошибка разная для тёмных и светлых участков?** Две причины складываются. Во-первых, SVD минимизирует суммарную ошибку по всей матрице: первые компоненты захватывают крупные однородные зоны, а ошибка копится на границах и текстурах (высоких частотах) — это видно на карте ошибки в ноутбуке. Во-вторых, по закону Вебера–Фехнера глаз чувствителен к относительным перепадам яркости, поэтому одинаковый по величине «шум» аппроксимации в тенях заметнее, чем в светах.
